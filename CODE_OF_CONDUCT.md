# Code of Conduct

## Our pledge

We want this project to be a place where people feel comfortable contributing regardless of experience level, identity, or background. We pledge to keep interactions respectful and constructive.

## Standards

Behave like a reasonable adult.

- Don't harass people
- Don't insult people
- Don't gatekeep
- Assume good intent
- If you disagree, argue the code not the person
- If someone asks you to stop, stop

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. If someone violates them, we may remove comments, PRs, or ban people temporarily or permanently.

To report an issue, open a GitHub issue or email the maintainer directly.

## Scope

This applies to all project spaces (issues, PRs, discussions) and public spaces when representing the project.
